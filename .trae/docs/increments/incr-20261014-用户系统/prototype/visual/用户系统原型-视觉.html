设计说明

本节为视觉原型配套说明，不进入任何界面。所有视觉决策均以「严格对齐现有 UI 体系」为第一原则，未引入新的配色或组件规范。

二、与现有组件的复用关系（开发时对齐）

  • NavBar：我的 / 完善资料页直接复用，毛玻璃与避让胶囊逻辑不变。
  • AppButton：主按钮（微信一键登录 / 保存）用 primary；「暂不登录」用 text 变体。
  • ConfirmDialog：注销二次确认零改动复用，仅传入标题/描述文案。
  • ActionSheet 弹层观感：登录引导底部弹层沿用其毛玻璃面板与圆角规范（$glass-panel-bg）。
  • Mascot：未登录头像与首页品牌区复用现有吉祥物资源（default 变体），不新增插画。

三、本次视觉处理的关键决策

  1. 未登录头像用吉祥物承载：避免「灰色空头像」的冰冷感，沿用产品既有的亲和调性；已登录后替换为用户头像。
  2. 危险操作降级呈现：退出/注销不做实心按钮，而是列表行 + 右侧 chevron，仅「注销账号」用危险色文字，符合「避免误触」的通行做法。
  3. 登录引导用底部弹层而非整页：用户点击「拍照录入」后就地弹出，含「暂不登录」可取消，不阻断浏览；符合小程序不得强制登录的审核要求。
  4. 昵称输入聚焦态：使用品牌绿描边 + 3px 柔光聚焦环，与现有主色体系一致（非默认蓝）。
  5. 动效克制：仅保留按钮按压（opacity .9）与卡片按压（scale .995），并遵循 prefers-reduced-motion；不做花哨入场动画，与现有页面风格一致。

四、同类产品参考（仅借鉴细节，不照搬风格）

  • 个人中心头块置顶、圆形头像可点改（通行范式）。
  • 未登录态以引导登录取代强制阻断（微信登录授权规范）。
  • 受限操作触发式登录 + 弹层含取消（小程序登录原型通行做法）。
  • 注销类危险操作二次确认并说明后果（账户与安全通行规范）。
