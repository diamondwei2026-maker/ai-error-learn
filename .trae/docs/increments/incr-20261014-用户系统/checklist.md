## B. 后端接口验收

- [ ] B1 `POST /api/v1/auth/login` 正常签发 access + refresh
- [ ] B2 未配置 `WECHAT_APP_SECRET` 时返回 `2003`，前端提示「登录暂不可用」
- [ ] B3 微信 code 无效返回 `2004`
- [ ] B4 `POST /api/v1/auth/refresh` 可换新 access；refresh 失效返回 `2002`
- [ ] B5 `GET /api/v1/user/me` 未带 token 返回 `401 / 2001`
- [ ] B6 `PATCH /api/v1/user/me` 昵称可更新并持久化；超长/非法返回 `2005`
- [ ] B7 `POST /api/v1/user/avatar` 上传成功返回新 `avatarUrl`；非图片/超 2MB 返回 `2006`
- [ ] B8 `POST /api/v1/user/delete` 后，`users` 与 `question_sync` 中该用户数据均为空
- [ ] B9 `POST /api/v1/sync/push` 新项插入、新者覆盖旧者（旧数据不覆盖新数据）
- [ ] B10 `GET /api/v1/sync/pull?since=` 仅返回该时间点之后的变更
- [ ] B11 同步数据跨用户隔离（A 用户无法读写 B 用户数据）
- [ ] B12 非法 `items` 结构返回 `3001`
- [ ] B13 `AUTH_REQUIRED=true` 时识别接口未带 token 被拒；`false` 时恢复旧行为
- [x] B14 `pytest` 全部通过（含既有 5 个测试文件，无回归）—— **已自动化验证：80 passed**
