已知二次函数 f(x)=x²-4x+3，求它在区间 [0,3] 上的最大值与最小值。
答案
f(x)=(x-2)²-1，对称轴 x=2 在区间内。
最小值 f(2)=-1；端点比较 f(0)=3、f(3)=0，
所以最大值 f(0)=3。

调研参考（视觉层，3 个同类产品）

  • Anki / AnkiMobile：复习界面极简，进度与翻面操作占据全部注意力，自评按钮成组出现且高度一致 → 本次自评两键等宽、等高。
  • Mochi：白底 + 单一强调色，卡片靠留白与字号层级区分，不使用多重边框 → 本次刷题页只用一张白卡 + 分割线。
  • Knowt：卡片大、字号大、列表干净，长时间学习不刺眼 → 本次题干 16/27、答案 16/27，辅助文字维持 13px 起。
  • 微信订阅消息：授权必须由用户点击触发，文案需说明「发什么、什么时候发」→ 引导卡固定说明 20:00 与到期数量。

视觉层增改点

  1. 首页：品牌区移除「MVP 核心闭环」标签与副标语，主标语与插画垂直居中，降低首屏信息密度。
  2. 首页：到期卡片建立「绿色主按钮 + 白色次按钮 + 底部提醒开关」三级结构；完成态切换为中性灰标签并移除主按钮。
  3. 首页：TabBar 刷题项加红色数字角标（需改用自定义 tabBar，原生 tabBar 不支持角标）。
  4. 刷题页：轮次标签替代原「随机」语义，其余进度、计时、翻面卡视觉完全复用。
  5. 刷题页：自评区用橙色弱底 / 绿色实心区分「没记住 / 记住了」，不加外框。
  6. 完成页：统计由两列扩为三列；订阅引导卡使用绿色渐变弱底，是全页唯一彩色模块。
  7. 空态：复用现有 Empty 组件视觉，按钮降为白底描边。

刻意保持不变

品牌区仅保留主标语与插画（本次移除「MVP 核心闭环」标签与副标语）、错题总数卡、拍照录入主入口、底部 TabBar 结构、导航栏、翻面卡尺寸与翻面交互、 全部沿用现有页面；未新增品牌色、未更换字体、未引入新组件库。

视觉阶段待确认

  • 首页到期卡片用绿色主按钮 + 橙色提醒开关，是否与底部「拍照录入」主入口争夺注意力。
  • 「没记住」用橙色弱底是否合适，或统一为白底描边、靠文字区分。
