调研参考（3 个同类产品 + 微信能力）

  • Anki：主界面用「新卡 / 学习中 / 待复习」三段数字表达工作量，图标角标显示总到期数，复习清零后角标自动消失 → 本题量表达方式。
  • 墨墨背单词：设置里有固定的「每日复习提醒时间」；若用户在提醒时间前已完成当天任务，当天不再提醒 → 完成即静默、固定时段的做法。
  • Duolingo：提醒文案强调「低摩擦的快速完成」并引用已积累的进度；连续 7 天不活跃后停止练习提醒 → 降频与停止策略。
  • 微信订阅消息：一次性订阅「授权 1 次 = 可发 1 条」；勾选「总是保持以上选择」后可静默累积额度；拒绝授权后 7 天内不可再次弹窗 → 决定订阅引导的时机与频次。

本次增改的节点

  1. 首页：品牌区移除「MVP 核心闭环」标签与副标语，仅保留主标语与插画。
  2. 首页：品牌区下方新增「今日待复习 / 今日已完成」双态卡片（同一位置切换）。
  3. 首页：TabBar 刷题项新增数字角标（到期题量）。
  4. 刷题页：不新增切换控件；有到期题直接按到期队列出题，无到期题展示空态，随机抽题不在本期范围。
  5. 刷题页：卡片背面下方新增「没记住 / 记住了」自评区。
  6. 完成页：新增订阅提醒引导卡片（统计区由两列改为三列）。

刻意保持不变

品牌区仅保留主标语与插画（移除「MVP 核心闭环」标签与副标语）、错题总数卡、拍照录入 / 开始刷题入口、卡片翻面交互、空状态与隐私弹层均沿用现有页面， 本次不改布局顺序、不新增一级页面、不改 TabBar 结构。

待确认

  • 首页待复习卡片放在品牌区下方是否合适，还是要更靠上/更靠下。
  • 「稍后」按钮是否需要（可能弱化行动力），或改为纯卡片点击进入。
  • 自评两档是否足够，是否需要第三档「有点模糊」。
  • 完成页统计是否需要「待巩固」这一列，或只保留题数与用时。
