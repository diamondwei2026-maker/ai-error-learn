## 四、降级与异常口径

| 场景                        | 表现                                                            |
| --------------------------- | --------------------------------------------------------------- |
| 模板 ID 为空 / 服务端未配置 | 不弹订阅面板，开关置为本地「站内提醒」，Toast「已开启站内提醒」 |
| 非微信端（H5）              | 不调用订阅 API，同上降级                                        |
| 用户拒绝授权                | 开关回退为关闭，Toast「未授权微信提醒」，不弹错误框             |
| 授权成功但上报失败          | 本地开关保留开启，仅记 warning，不阻塞复习                      |
| 同一 session 重复点击       | 不重复弹面板，Toast「已开启提醒」                               |
| 游客点击                    | 首页弹登录引导；刷题完成页 Toast「请先登录后再开启提醒」        |
