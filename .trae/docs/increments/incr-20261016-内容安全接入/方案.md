# incr-20261016-内容安全接入 · 增量方案

> 编号：`incr-20261016-内容安全接入` ｜ 日期：2026-10-16 ｜ 类型：普通增量（走 `/plan`）
> **权威长文方案**：`.trae/documents/微信内容安全接入改造方案.md`（本文件为增量卡片，避免与其重复维护）

## 1. 目标

接入微信内容安全能力，覆盖全部 UGC 写入点，规避小程序审核风险。

## 2. 范围与决策

| # | 决策项 | 结论 |
| --- | --- | --- |
| D1 | 校验范围 | 昵称 + 错题题干/答案文本 + 头像图片 |
| D2 | 文本拦截层 | 保存前预检 + 服务端 `sync/push` 兜底 |
| D3 | 降级策略 | 接口不可用/未配置/无权限 → 放行 + 记日志 |
| D4 | `suggest == "review"` | 放行 + warning 日志（仅 `risky` 拦截） |
| D5 | 文本送检粒度 | 每题一次调用（content + "\n" + answer 合并） |
| D6 | 回调加解密模式 | 明文模式（仅 SHA1 验签，不新增依赖） |
| D7 | 送检量控制 | 仅对新增/`updatedAt` 变新的错题送检 |
| D8 | 图片命中处置 | 回调命中 → 删除头像文件 + 清空 `avatar_url`（静默） |
| D9 | 文本兜底命中处置 | 不落库 + `push` 响应 `rejected`；前端仅记日志 |
| D10 | 原型流程 | 无新增页面/无 UI 视觉改动 → 不触发双阶段原型 |
| D11 | 本地敏感词表 | 不做 |

## 5. 上线前置（不阻塞编码，阻塞生效）

1. MP 后台 IP 白名单加入 ECS 公网出口 IP（否则 `40164`）
2. MP 后台「消息推送」：URL `https://<域名>/api/v1/wechat/callback`、Token 与 `.env` 一致、数据格式 JSON、明文模式
3. `.env` 配置 `CONTENT_SECURITY_ENABLED=true`、`PUBLIC_BASE_URL`、`WECHAT_CALLBACK_TOKEN`
4. 域名已备案且 `/static/avatars/*` 可被外网直接下载

## 6. 回滚

`CONTENT_SECURITY_ENABLED=false` 即整体降级放行；代码级回滚 `git checkout <上一可用提交> -- server/ client/`；新增表为纯追加。
