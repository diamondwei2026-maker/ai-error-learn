2a · 隐私政策

一、我们收集的信息

我们仅收集为你提供服务所必需的信息：

  • 你主动拍摄或从相册选择的题目图片；
  • 你授权的微信头像与昵称；
  • 用于识别账号的微信登录标识。

二、信息的使用

题目图片仅用于识别题目中的文字，帮助你建立错题记录；头像与昵称用于在应用内展示；登录标识用于在多设备之间同步你的错题数据。我们不会将上述信息用于与服务无关的用途。

三、第三方共享

为实现题目文字识别，你上传的题目图片会传输至第三方多模态大模型服务进行处理。除该识别用途外，我们不会向任何第三方出售或共享你的个人信息。

四、存储与安全

你的错题数据存储于云端数据库与服务器文件中，我们在传输过程中采取加密措施加以保护。

五、你的权利

你可以随时在「我的 → 完善资料」中更正头像与昵称；也可以通过「我的 → 注销账号」删除账号及全部云端数据，该操作不可恢复。

六、未成年人保护

如果你未满 18 周岁，请在监护人陪同下阅读本政策并使用本服务。

七、联系我们

如对本政策有任何疑问，可通过小程序「我的」页面提供的联系方式与我们联系。

设计说明 · 阶段2 视觉

阶段2设计令牌 100% 取自现有 theme.scss / variables.scss，未新增任何颜色、圆角、阴影或字体。界面内文案均为真实用户可见文案。

一、与现有 UI 体系的对齐点

元素取值来源
弹层面板圆角 16px 16px 0 0、毛玻璃 rgba(255,255,255,.92) + blur(30px)、顶部 1px 描边 —— 与 LoginSheet / ActionSheet 完全一致
遮罩rgba(15,23,42,.3) + blur(2px) —— 与现有 .mask 一致
主按钮AppButton primary：胶囊、#07c160、50px 高、17px/600
文字按钮AppButton text：无底、#4b5563、15px/400
列表行复用「我的」页现有 .row（高 54px、rgba(17,24,39,.04) 分隔线）
正文排版小标题 14.5px/600，正文 13px / 行高 1.85，颜色 #4b5563 —— 与项目正文规范一致

二、视觉细节取舍

  • 弹层无关闭「×」：所有退出路径都由「暂不授权」承担，避免用户误以为可绕过。
  • 协议链接用下划线而非变色实体按钮：视觉权重低于主按钮，符合「链接 < 次要按钮 < 主按钮」的层级。
  • 协议页正文用纯文本分段（小标题 + 段落 + 少量列表），不引入富文本依赖，与项目「不新增依赖」原则一致。
  • 「服务协议」区块用灰字小标题分隔，弱于卡片内的操作行，避免与「退出登录 / 注销账号」争夺注意力。
  • 图标统一为内联 SVG（无 emoji），尺寸固定，风格与现有 tabBar 图标一致。

三、同类产品的视觉处理（借鉴点）

  • 隐私弹层普遍不打断整屏、不做全屏强制页，而是底部面板 + 明确拒绝入口 —— 与本次方案一致。
  • 协议页普遍采用超长可滚动正文 + 顶部返回，不加底部操作栏 —— 本次沿用。
  • 协议入口通常放在「我的」页底部且登录前后均可见 —— 本次沿用。
