## 1. 摘要（Summary）

把现有《部署教程》从"懂技术的人看的操作手册"，改写为**零基础也能照着做**的版本。

用户已确认的三条前提（本轮澄清）：

| 项 | 结论 | 对教程的影响 |
| --- | --- | --- |
| 怎么操作服务器 | **阿里云控制台「远程连接」网页版（Workbench）** | 每个命令都要标注"在 Workbench 黑框里执行"，并教怎么打开/粘贴/中断 |
| 代码怎么上云 | **从 GitHub 克隆** | 需先装 git、给出完整仓库地址，并提醒"本地最新代码要先 push" |
| 数据库怎么建 | **RDS 控制台图形化建库** | 用"点哪里 → 看到什么"的方式写，不要求写 SQL |

沿用上一轮已确立的场景主线（已有原生 Nginx 站点、80/443 被占、独立 RDS、新开备案子域名），**不改变技术方案**，只**改变讲法与粒度**。

核心新增：① 开篇讲清"你要操作的两个窗口"；② 逐步教**登录服务器（Workbench）**；③ 逐步教**把代码下载到服务器**；④ 逐步教**在控制台建库 error_learn**；⑤ 每步都给"**执行后应该看到什么**"的验证点；⑥ 附录给**可整段复制的命令清单**与**术语小词典**。

| **0. 先读这一页** | 讲清**两个窗口**：① 阿里云控制台（网页，用来建库/加白名单/看实例）；② ECS 远程连接 Workbench（黑框命令行，用来敲命令）。给"术语小卡片"：命令行、`sudo`、路径、提示符 `$`/`#`、怎么粘贴（`Ctrl+Shift+V` 或右键）、怎么中断（`Ctrl+C`） |
| **1. 目标架构** | 保留架构图，文字口语化；说明"你只要照着 §3 起一步步做" |
| **2. 开工前准备** | 用勾选清单：已有 ECS / 已有（或即将创建）**独立 RDS 实例** / 已有备案主域名 / 小程序 AppID。**若 RDS 实例还没建，给创建指引**（控制台 → RDS → 创建实例 → 选 MySQL 8.0 → 与 ECS 同地域） |

| **4. 第二步：摸清服务器现状** | 保留 7 条勘察命令，但**每条补三行**：敲什么 / 该看到什么 / 怎么判断（例如"8000 是否被占"→ 有输出=被占）。结论表保留 |
| **5. 第三步：把代码下载到服务器**（新增/改写） | ① 先 `git --version`，没有则 `sudo apt update && sudo apt install -y git`；② **前置提醒：本地先 `git push`**（附本地执行 `git push` 的位置说明）；③ `sudo git clone https://github.com/diamondwei2026-maker/ai-error-learn.git /opt/error-learn`；④ 验证点：`ls /opt/error-learn` 应看到 `client server deploy .trae` 等；⑤ 常见失败：GitHub 超时/连不上 → 重试、改用 Gitee 镜像或打包上传（给一句话简述，不展开） |
