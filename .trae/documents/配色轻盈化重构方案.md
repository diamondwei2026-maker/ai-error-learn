# 配色轻盈化重构方案（v3）

> 目标目录：`d:\Users\weij\ai-error-learn\deepseek-design`
> 目标文件：`错题本原型-01-录入与入库.html`、`错题本原型-02-题库管理.html`、`错题本原型-03-刷题复习.html`
> 用户诉求：「配色不够轻盈」

---

## 1. Summary

在不改动任何布局、结构、文案、屏数、交互说明、毛玻璃位置、吉祥物造型与字号体系的前提下，只调整**颜色令牌与外壳配色**，把整体观感从「暖米灰 + 近黑包边 + 大面积饱和薄荷绿」转向「中性冷白 + 浅色细边框 + 极淡色块 + 柔和浮起」，实现「轻盈」的视觉重量下降。

已与用户确认的两个方向：

| 决策点 | 选择 |
| --- | --- |
| 规格页 13 个手机框的近黑包边 | **换成浅色细边框**（白内圈 + 浅灰外圈 + 柔和投影） |
| 页面底色与描边色相 | **中性冷白 / 近白**（放弃现有暖米灰） |

## 4. Assumptions & Decisions

1. **「轻盈」的判定标准** = 降低视觉重量：更亮的底色、更浅更冷的描边、更少的饱和色块与深色块、用柔和阴影替代硬边框；同时**保持**正文对比度 ≥ 4.5:1。
2. **保留品牌色**：`#07C160` 及其语义色（蓝=复习、橙=提醒、红=删除）不动，只收敛它们的浅色底与使用面积。
3. **卡片新增极柔阴影**，这与 UI 原型设计方案 §3.5「卡片默认无阴影」有轻微偏离。这是本次「轻盈化」的主动决策（用浮起替代硬框），且属于规格页/原型层表现，需在交付说明中标注。
4. **深色硬件元素保留**：灵动岛 `.island`、Home 指示条 `.home-indicator` 属设备真实感，保留深色，仅统一为冷调。
5. 三份文件的同名声明**必须替换为完全相同的值**，以保证三页视觉一致；替换后需逐一比对 `:root` 与外壳样式块是否仍逐行一致。
6. 文件当前为 Prettier 展开格式，且编辑器存在保存即格式化的行为；每次编辑后应重新读取确认最终落盘格式，避免匹配失败。
