> 前置条件：后端已启动（`uvicorn app.main:app --host 0.0.0.0 --port 8000`），且 `client/src/constants/index.ts` 的 `RECOGNIZE_API_BASE` 与本机局域网 IP 一致；测试环境为微信小程序（weapp）。

- [ ] B1【正常】从首页拍照/选图后进入编辑页，先展示「识别中」态（缩略图 + 进度条 + 百分比）

- [ ] B3【正常】图片含解答时答案框被回填，提示为「AI 已识别解答 · 请校对」

### B.2 表单校验与保存

- [ ] B8【正常】题干有内容时「保存入库」可点击，点击后 Toast「已保存」并跳转题库
- [ ] B9【正常】题干为空时「保存入库」为禁用态，不可保存
- [ ] B10【正常】保存后题库列表出现该题，首页总数 +1
- [ ] B11【正常】答案可留空仍可保存

- [ ] B14【边界】答案含多行解题过程（换行）：保存后答案换行被保留
- [ ] B15【异常】重复点击「保存入库」不产生重复记录（`saved` 去重）

### B.3 识别异常路径（后端未配置密钥/失败时）

- [ ] B16【异常】后端未配置密钥（`VISION_ENABLED=false` 或 key 为空）：进入编辑页后题干为空，Toast 提示「识别失败，请手动输入」，流程不中断
- [ ] B17【异常】识别超时（>30s）：判定失败，题干留空并提示手动输入
- [ ] B18【异常】后端不可达（服务未启动/网络不通）：判定失败，题干留空并提示手动输入
- [ ] B19【异常】后端返回 1002：前端提示「识别失败，请手动输入」
- [ ] B20【异常】后端返回 1003（配额/限流）：前端提示「识别额度受限，请稍后再试」
- [ ] B21【异常】后端返回 1004（图片无效/过大）：前端提示「图片无效或过大，请重新拍摄」
- [ ] B22【异常】后端返回 1005（未开通/无权限）：前端提示「识别服务未开通或无权限，请联系管理员」
- [ ] B23【正常】识别中态点击「取消识别」返回上一页

## E. 后端接口（可用 curl / pytest / TestClient 验证）

- [ ] E1【正常】`GET /api/v1/health` 返回 `200 {"status":"ok"}`
- [ ] E2【正常】`POST /api/v1/recognize` 上传合法图片（已配置密钥）→ `code=0`，`text` 非空
- [ ] E3【正常】上传含解答的图片 → `answer` 非空、`splitMethod="vlm"`
- [ ] E4【正常】上传仅题干图片 → `answer=""`、`splitMethod="none"`
- [ ] E5【正常】`wordsCount` 等于题干去除空白后的字符数
- [ ] E6【异常】上传空文件 → `code=1004`
- [ ] E7【异常】上传超过 `VISION_MAX_IMAGE_BYTES` 的文件 → `code=1004`
- [ ] E8【异常】上传非图片（如 txt）→ `code=1004`
- [ ] E9【异常】上游返回 429 / 限流文案 → `code=1003`
- [ ] E10【异常】上游返回 401/403 或鉴权文案 → `code=1005`
- [ ] E11【异常】上游 5xx / 网络异常 / 响应结构异常 → `code=1002`
- [ ] E12【正常】`POST /api/v1/ai/variants` 返回 HTTP `501` 且 body 为 `{"code":9001,"message":"AI 功能未启用"}`
- [ ] E13【边界】模型返回带 ```` ```json ```` 围栏 / 前后夹带说明文字 / answer 含未转义换行时，仍能正确解析出题干与答案
