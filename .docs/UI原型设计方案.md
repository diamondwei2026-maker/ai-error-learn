## 1. 设计目标与原则

### 1.1 目标

- 让"整理错题"这件枯燥的事**看起来轻松**：视觉干净、层级清晰、无压迫感。
- 服务于**高频、单手、碎片时间**的使用场景：拇指可达区域内完成核心操作。
- 在同类产品（普遍蓝/靛蓝）之外做出区隔，用微信绿传递"进步感"，并以毛玻璃强化现代感。

### 1.2 原则

| 原则         | 说明                                                                             |
| ------------ | -------------------------------------------------------------------------------- |
| 极简优先     | 不引入富文本、公式渲染、图文混排；题干一律纯文本                                 |
| 一屏一重点   | 每屏只有一个主行动点（如"保存入库""显示答案"）                                   |
| 轻盈优先     | 底色近白、描边极淡、深色块克制；用**极柔浮起阴影**与留白建立层级，而非硬边框     |
| 卡片承载信息 | 内容以卡片为基本容器：白底 + 细描边 + 12px 圆角 + 极柔浮起阴影，不用重阴影       |
| 颜色即语义   | 绿=主行动/成长，蓝=复习类次功能，橙=待复习，红=删除/错误                         |
| 不做多余装饰 | 不用渐变、噪点、炫光；靠留白、字重、间距与柔和阴影建立层级                       |
| 形象克制     | 卡通形象只出现在情绪节点（品牌区、等待、成功、空态、完成），不侵入正文卡片与列表 |

## 2. 竞品与行业设计风格调研

### 2.1 同类产品设计特征

| 类型        | 代表产品               | 设计特征                                             | 可借鉴点                             |
| ----------- | ---------------------- | ---------------------------------------------------- | ------------------------------------ |
| 拍照搜题    | 作业帮、小猿搜题       | 白 + 蓝为主、冷色调、卡片列表、大按钮                | 列表卡片的信息密度、拍摄入口的强引导 |
| 错题本垂类  | 今知错题本、WQN 错题本 | "卡片式错题本"隐喻、多层级分类、掌握状态色标、热力图 | 状态色标体系、卡片翻面复习           |
| 测验 / 学习 | Quizlet、Kahoot 系     | 浮起白卡片 + 柔和底色 + 大号题号                     | "专注"氛围、大号题号的进度心理锚点   |

### 2.2 行业配色统计（教育类 App）

- 背景色占比：**白 44%**、蓝 20%、黑 7%、青绿 6%、绿 5%
- 主题明暗：**浅色 50%**、混合 30%、深色 20%

### 2.3 调研结论

1. 主流形态是 **浅色底 + 单一主色 + 白色浮起卡片 + 圆角**，本方案沿用以降低用户学习成本。
2. 同类产品几乎全部使用蓝 / 靛蓝系；本项目采用**微信绿 `#07C160`**——既是"积极向上"的成长色，也让用户获得与微信一致的**原生熟悉感**。
3. 错题类产品的关键体验是**"卡片"隐喻**（录入即卡片、列表即卡片、复习即翻面卡片），本方案全程贯穿该隐喻。
4. 半透明与模糊是现代微信小程序的通行质感，本方案在**导航栏、tabBar、吸底操作条、弹层**四处引入**毛玻璃**，强化层次而不干扰阅读。
5. 深色大块（近黑包边、纯黑胶囊、深色 Toast）会显著压沉画面；本方案**以浅色细边框 + 极柔阴影替代**，换取更轻盈的观感（v1.3）。

### 3.1 设计关键词

### 3.2 色彩系统（对齐微信官方色板）

| 角色               | 色值                                                                 | 用途                                                                  |
| ------------------ | -------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 微信绿（主色）     | `#07C160`                                                            | 主按钮填充、进度条、选中图标、关键强调（对齐微信官方绿）              |
| 微信绿（深）       | `#06AD56`                                                            | 按压态、进度条轨道填充                                                |
| 深绿（文字）       | `#056B36`                                                            | 浅绿底 / 白底上的绿色文字、tabBar 选中态（对比度 ≈ 6:1）              |
| 浅绿底             | `#F0FBF5`                                                            | 标签底、信息卡底、选中态底色                                          |
| 浅绿底（强）       | `#E4F8EE`                                                            | 主入口卡片底、重点区块底（须配 1px 绿描边）                           |

| 提醒橙             | `#F5943C`                                                            | "待复习 / 进行中"状态、提醒类信息                                     |

| 警示红（删除）     | `#F5514E`                                                            | 删除操作、错误与失败状态                                              |
| 红（文字）         | `#BE322F`                                                            | 白底上的红色文字、危险按钮文字                                        |
| 主文本             | `#1F2937`                                                            | 标题、题干正文（对比度 ≈ 14.7:1）                                     |
| 常规文本           | `#4B5563`                                                            | 说明文字、时间、辅助信息（对比度 ≈ 7.6:1）                            |
| 次要文本           | `#6B7280`                                                            | 字数、极弱提示（对比度 ≈ 5.1:1；占位符 / 禁用态可用，不承载关键信息） |
| 分割线 / 描边      | `rgba(17,24,39,0.07)`                                                | 卡片描边、列表分割线（次级分隔线 `rgba(17,24,39,0.04)`）              |
| 遮罩               | `rgba(15,23,42,0.30)`                                                | 弹窗 / ActionSheet 遮罩（配 `blur(2px)`）                             |
| 页面底色（手机屏） | `#FAFBFD`                                                            | 手机屏背景，近白冷调                                                  |
| 卡片底色           | `#FFFFFF`                                                            | 卡片、面板、弹层                                                      |
| 规格页底色         | `#F5F7FA`                                                            | HTML 原型中手机框之外的规格页背景                                     |
| 极柔浮起阴影       | `0 1px 2px rgba(17,24,39,.03), 0 10px 24px -16px rgba(17,24,39,.12)` | 卡片默认阴影（见 §3.4）                                               |
| 浮动投影           | `0 10px 30px -12px rgba(17,24,39,.16)`                               | Toast、弹窗、FAB 等浮层                                               |

**用色规则**

1. 一块区域内**最多 2 个语义色**，避免"彩虹色"。
2. 绿色只用于**主行动点、选中态与成长类正向信息**，不做大面积饱和装饰底；主入口卡片改用**极淡薄荷 `#E4F8EE` + 1px 绿描边**，既保留"主行动"语义又降低视觉重量。
3. 红色 `#F5514E` **仅**用于删除/错误，不做强调色使用；白底上的红色文字用 `#BE322F` 保证对比度。
4. 正文与背景对比度不低于 4.5:1：白底正文用 `#1F2937` / `#4B5563`；近白底（`#FAFBFD`）上的弱化文字用 `#6B7280`；浅绿底上的文字用 `#056B36`；主绿填充上的文字用白 `#FFFFFF`。
5. > 注意：`#07C160` 上放白字对比度约 2.4:1，属微信原生做法（仅用于 ≥16px 粗体按钮）。若某处需放置小字号文字，改用 `#06AD56` 填充，或直接改走 `#056B36` 文字色。
6. **深色块克制**：除设备硬件元素（灵动岛、Home 指示条）外，页面内不出现大面积深色块；Toast 等反馈由深色胶囊改为浅色胶囊（见 §3.5）。

### 3.3 字体层级（对齐微信设计指南）

> 微信设计指南建议：字体与所运行系统保持一致；本方案常用字号为 **24 / 19 / 17 / 16 / 15 / 13 / 12**。
> 小程序端**不引入自定义字体**（包体积与渲染一致性），统一使用中文系统字体栈：
> `"PingFang SC", "HarmonyOS Sans SC", "MiSans", "Source Han Sans SC", "Noto Sans SC", "Microsoft YaHei UI", "Microsoft YaHei", system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`
> **全端不使用等宽字体**（含原型规格页与代码片段标记）；数值对齐改用 `font-variant-numeric: tabular-nums`。

| 层级            | 字号 / 行高 | 字重 | 用途                                       |
| --------------- | ----------- | ---- | ------------------------------------------ |
| 页面主标题      | 24 / 34     | 600  | 品牌区标题、完成页标题                     |
| 区块标题        | 19 / 28     | 600  | 空态主文案、区块大标题                     |
| 导航 / 卡片标题 | 17 / 26     | 600  | 导航栏标题、卡片主标题、按钮文字（17/600） |
| 题干正文        | 16 / 27     | 400  | 题干、答案正文（阅读舒适优先）             |
| 常规正文        | 15 / 23     | 400  | 列表项、说明文字、弹窗说明                 |
| 辅助说明        | 13 / 20     | 400  | 时间、字数、进度说明、提示语               |
| 标签文字        | 12 / 16     | 600  | 状态标签、角标                             |

**排版规则**

- 题干在列表中**最多 2 行**截断（`-webkit-line-clamp: 2`），详情页与刷题页完整展示。
- 一屏最多使用 **2 种字重**（400 / 600），靠字号与颜色区分层级，不用第三种字重。
- 数值（题号、用时、统计数字）统一走系统字体栈 + `tabular-nums`，**不得回退为等宽字体**。

- 白底 `#FFFFFF` + 1px 描边 `rgba(17,24,39,.07)` + 圆角 12px + 内边距 16px。

**标签（Chip）**：圆角胶囊，高 22px，左右内边距 9px，字号 12/600；浅绿底 `#F0FBF5` 用于正向信息，浅蓝底 `#EFF8FE` 用于复习类信息，浅灰底 `rgba(17,24,39,.045)` 用于中性信息。

**输入框**：圆角 8px，内边距 12px，描边 `rgba(17,24,39,.07)`；聚焦态描边加粗至 2px 并切为主绿 `#07C160`；题干框高度 ≥ 160px，答案框高度 ≥ 100px。

**弹窗（Dialog）**：居中卡片，宽 280px，圆角 16px，含图标 + 标题 + 说明 + 双按钮；遮罩 `rgba(15,23,42,.30)` + `backdrop-filter: blur(2px)`；面板投影 `0 24px 60px -20px rgba(15,23,42,.20)`。

**Toast**：居中胶囊，**浅底** `rgba(255,255,255,.97)` + 1px 描边 `rgba(17,24,39,.07)` + 柔和投影 + **主绿对勾 + 深色文字 `#1F2937`**；显示 1.5s。（v1.3 由深色胶囊改为浅色胶囊，避免页面出现深色块。）

**空态**：SVG 卡通形象（尺寸见 §3.8，可配虚线空卡片与"?"）+ 主文案 19px + 说明 15px + 行动按钮，整体垂直居中。

**tabBar**：高 56px（另加 22px 底部安全区），3 项，图标 23px + 文字 12px；**选中态 `#056B36`**，未选中 `#4B5563`；背景走毛玻璃（见 3.6）。（选中态使用深绿而非 `#07C160`，以保证 12px 小字号对比度 ≥ 4.5:1。）

**FAB（录入悬浮按钮）**：56px 圆形，`#07C160` 填充 + 白色"+"图标，投影 `0 10px 24px rgba(7,193,96,.26)`，距右 16px、距 tabBar 上方 16px。

### 3.6 毛玻璃（Frosted Glass）规范

在**四处**使用毛玻璃，其余区域保持纯色以保障阅读清晰度。

| #   | 位置                          | 背景                     | 模糊                        | 作用                                       |
| --- | ----------------------------- | ------------------------ | --------------------------- | ------------------------------------------ |
| ①   | 顶部导航栏                    | `rgba(255,255,255,0.78)` | `blur(20px) saturate(180%)` | 内容滚动时从导航栏下透出，是"微信感"的关键 |
| ②   | 底部 tabBar                   | `rgba(255,255,255,0.84)` | `blur(24px) saturate(180%)` | 列表滚到底部时不生硬                       |
| ③   | 吸底操作条 / 答案浮层         | `rgba(255,255,255,0.72)` | `blur(16px) saturate(180%)` | 编辑页"保存入库"条、刷题页操作条           |
| ④   | 弹层 / ActionSheet / 弹窗面板 | `rgba(255,255,255,0.92)` | `blur(30px) saturate(180%)` | 录入方式选择、删除确认                     |

**硬性约束**

1. 模糊半径控制在 **12–24px**（弹层可到 30px）；超过 24px 文字边缘易发虚。
2. 必须同时书写 `-webkit-backdrop-filter` 以兼容旧版 iOS 内核。
3. 必须提供降级：`@supports not (backdrop-filter: blur(1px))` 时回退为接近不透明的纯色底 `rgba(255,255,255,0.97)`。
4. 毛玻璃层上**不放置 12px 以下的小字**（如角标），避免模糊背景导致可读性下降。
5. 毛玻璃容器必须有 1px 描边（`rgba(17,24,39,.07)`）或 0.5px 分隔线，否则在浅色内容上会"糊掉边界"。
6. **不使用毛玻璃**的区域：正文卡片、表单输入框、列表项、按钮。
7. v1.3 起，四处毛玻璃的白色不透明度整体上调（0.72→0.78、0.80→0.84、0.66→0.72、0.90→0.92），在更亮的近白底色上仍能稳定区分层次。

**参考样式**

```css
/* ① 顶部导航栏 */
.navbar {
  background: rgba(255, 255, 255, 0.78);
  backdrop-filter: blur(20px) saturate(180%);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  border-bottom: 1px solid rgba(17, 24, 39, 0.07);
}
/* ② 底部 tabBar */
.tabbar {
  background: rgba(255, 255, 255, 0.84);
  backdrop-filter: blur(24px) saturate(180%);
  -webkit-backdrop-filter: blur(24px) saturate(180%);
  border-top: 1px solid rgba(17, 24, 39, 0.07);
}
/* 降级 */
@supports not (backdrop-filter: blur(1px)) {
  .navbar,
  .tabbar,
  .action-bar,
  .sheet {
    background: rgba(255, 255, 255, 0.97);
  }
}
```

### 3.7 图标规范

- 线性风格，描边 1.8px，圆头圆角，尺寸 20 / 22 / 24px 三档。
- 统一 `currentColor` 着色，不混用面性图标。
- **不使用 emoji 作为图标**。
- 核心图标：首页、题库、刷题、相机、相册、对勾、垃圾桶、右箭头、左返回、加号、刷新、锁、时钟、警示。

### 3.8 卡通形象规范（v1.3 新增）

- **形象**：内联 SVG「小错题本」——圆角笔记本造型，绿色描边 `#0E8F52` + 橙色书签 `#FFC078` + 腮红 `#FFC7A6`，地面阴影 `rgba(15,23,42,.07)`；整体扁平、圆润、无渐变。
- **实现**：以 `<symbol id="mascot" viewBox="0 0 120 120">` 定义一次，页面内用 `<use href="#mascot">` 复用；每个 HTML 原型文件内联一份，保证三页一致且不依赖外部资源。
- **出现位置（共 5 处）**：

| 页面          | 尺寸      | 说明                                                                |
| ------------- | --------- | ------------------------------------------------------------------- |
| 01 首页       | 104px     | 品牌区右侧，与 slogan 并排                                          |
| 03 OCR 识别中 | 86px      | 水平居中，缓解等待感                                                |
| 05 保存成功   | 78px      | 水平居中，位于成功提示之上                                          |
| 07 题库空态   | 220×170px | 与虚线空卡片、"?" 组合，整体居中                                    |
| 12 本轮完成   | 220×180px | 与星星、彩色纸屑（`#FFC078` / `#07C160` / `#12A8F0`）组合，整体居中 |

- **动效**：`floaty` 上下浮动 4.5s 缓入缓出（`translateY(0 → -6px)`）；**必须遵循 `prefers-reduced-motion: reduce`**，在该媒体查询下关闭全部动画与过渡。
- **约束**：形象不叠加在正文卡片、列表项、按钮与毛玻璃层之内；同一屏最多一个形象。

## 8. 待明确 / 后续范围

1. 本期原型**仅覆盖 MVP 核心闭环**；扩展功能（账号与订阅、多维分类、掌握度与统计、艾宾浩斯复习、AI 变式题、知识库出题）按同一套设计规范另行出图。
2. 深色模式：本方案仅交付浅色主题，深色主题待后续评估（小程序端非必需）；若后续要出深色主题，需重新标定 §3.2 的中性色阶与卡片阴影。
3. 缩略图与"看大图"的具体交互（全屏预览、双指缩放）待交互评审确认。
4. 字体：小程序端维持中文系统字体栈，**并明确不使用等宽字体**；如后续需要品牌感，可在 H5 端引入中文标题字体。
5. **本地容量展示（占用进度、超限提醒、清理引导）本期不在原型中呈现**；首页数据概览只展示"错题总数"。若后续需要，可作为设置项单独补充。
6. 卡通形象「小错题本」目前以内联 `<symbol>` 实现，仅覆盖 5 个情绪节点；如需扩展（如加载失败、网络异常），沿用 §3.8 的造型与配色规则。
7. 主绿 `#07C160` 上放白字的对比度约 2.4:1，属微信原生做法；若后续需要满足更严格的对比度标准，可整体下沉为 `#06AD56` 或为按钮文字加描边，届时应作为一次独立的色彩调整评估。
